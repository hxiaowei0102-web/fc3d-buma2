## 0. 一句话总结

本项目是**福彩3D 两码不组**预测器（移植自 `D:\百十个杀一码\` 公式穷举框架）：
每晚定时抓最新开奖 → 用最近 **300 期（主）与 500 期（副）双窗口**各自暴力穷举约 **4074 万条线性公式**（59特征，输出 mod 45 查 45 对表）→ 各挑 1 条最优公式（无备用）→ 预测一对**不同数字 (a,b)** 断言下期**不会同时出现** → 固定公式做逐期回测 → 生成手机端网页 → 部署 GitHub Pages，每天真实留痕 + 次日自动验证。

## 1. 玩法定义与核心概念（必须先懂）

| 概念 | 定义 |
|---|---|
| **开奖号** | 福彩3D 每期开出 3 个数字：百位 / 十位 / 个位，各 0-9 |
| **两码不组** | 预测一对**不同数字** (a,b)，断言下期三位开奖中 a、b **不会同时出现** |
| **命中** | 开奖号去重后 a、b 不同时出现 → 命中。随机基线 ≈ **94.6%**（45 对中当期平均同现 2.43 对） |
| **同现对** | 当期开奖号（去重）中任意两个不同数字组成的对。如 695 → {56,59,69}；455 → {45}；豹子 555 → 空 |
| **公式** | 形如 `2*S+3*so+6` 的线性表达式，输入上期（及前2期）开奖，输出 0-44 → 查 45 对表得 (a,b) |
| **窗口** | 只取最近 N 期历史挑选公式。主窗口 N=300、副窗口 N=500（2026-09-02 walk-forward 样本外扫描固化：300 命中最高 97.5%、500 极差最小 1.67pp）。两窗口各挑各的公式、各自独立跟踪 |
| **不偷看未来** | 第 i 期预测只允许用第 i-1（上期）、第 i-2（前2期）数据，代码层面强制保证 |

**注意**：命中率 ~96% 只代表"窗口内该公式最准"（历史拟合/幸存者偏差），样本外真实水平接近 94.6% 基线。

### 硬约束（两码不组的"不组"语义）
1. **两个数字不能重复**：预测对是 (a,b) 且 a<b。公式输出 ∈[0,45) 查 PAIRS 表天然满足，代码不可能输出 44/55 这种重复对。
2. **（v2 已移除）预测对须与上期不同**：v1 曾要求预测对不得 ∈ 上期开奖同现对集合、并剔除冲突桶、双撞跳过；
   v2 起去掉此约束，每期**永报唯一主推**（无备用、无跳过）。预测对可能与上期同现对相同（历史约 0~2 期/120期），照常计入命中/失误。

## 2. 公式数学定义

### 2.1 一条公式长什么样
```
结果 = ( c1 × 特征F1 + c2 × 特征F2 + c3 × 特征F3 + const ) mod 45
```
- `c` 系数 ∈ {1,2,3,5}（三特征限定 {1,2,3} 控规模）
- `const` 常数 0-44（比杀一码的 0-9 宽 4.5 倍，覆盖全部 45 对）
- 特征取"个位"（mod 10），结果 0-44 查 `PAIRS[v]=(a,b)`

### 2.2 公式池规模（≈4074万 规格）
| 组合 | 数量估算 | 系数集 |
|---|---|---|
| 单特征 | 59 × 4 × 45 = 10,620 | (1,2,3,5) |
| 双特征 | C(59,2) × 4×4 × 45 = 1,231,920 | (1,2,3,5) |
| 三特征 | C(59,3) × 3×3×3 × 45 ≈ 3948.6万 | (1,2,3) |
| **合计** | **≈ 4074万** | |

### 2.3 45 对表
PAIRS = [(0,1),(0,2),...,(0,9),(1,2),...,(8,9)]，下标即公式输出值。`P2I` 反向映射。

### 2.4 59 个特征全表
与百十个杀一码完全一致（A组34上期单期 + B组9上期派生 + C组16跨期），见 formulas.py 或百十个杀一码文档。

## 4. 核心模块关键逻辑（AI 接手必读）

### bruteforce.py —— 穷举 + 分桶（与杀一码最大的不同）
- 特征矩阵 F(window×59)：第 k 期特征用第 k-1/k-2 期开奖
- 当期同现布尔矩阵 M(window×45)：M[k,v]=第k期开奖含对v
- 上期间现布尔矩阵 Mp(window×45)：Mp[k,v]=第k-1期开奖含对v（conf，仅同分裁决用）
- **命中数** = window - Σ(M[ar,out])，即预测对不在当期同现对集合的期数
- **分桶设计**：每公式算 `v_next`（用窗口最新一期开奖做上期特征 → 下期预测对索引）。按 v_next 分45桶，每桶只留命中最高公式。末尾排序取 hits 最高的**一个桶 = 唯一主推**（v2：不再剔除撞上期桶、无备用）
- 并列裁决：命中率 → conf 更小 → 公式更短 → 字典序

### backtest.py —— 回测/预测（v2）
预测第 i 期：**永远报唯一主推的预测对**，不判撞上期、不切备用、不跳过。命中 = 预测对 ∉ 当期同现对集合。

### track_predictions.py —— 双窗口独立跟踪
首次启用回填 500 期（backfill），之后只做真实每日跟踪（live）：验证昨日 pending + 记录今日预测（开奖前落盘）。hard 约束在 `_resolve_pair` 统一实现，回填/新增/预测同一套逻辑，杜绝口径漂移。

### gen_site.py —— 页面
- 页面预测优先取该窗口跟踪日志最新 pending（开奖前真实落盘值），无 pending 才公式重算 —— 保证页面与跟踪日志一致
- 两个数字方块并排展示，紫色渐变头部 + 黄色横幅 + 蓝色数字方块 + 绿红回测表（复刻杀一码视觉，适配不组玩法）

## 6. 与杀一码框架的差异对照（移植说明）

| 维度 | 百十个杀一码 | 两码不组（本项目） |
|---|---|---|
| 预测目标 | 每位置杀1码（mod 10） | 1对不组两码（mod 45 查45对表） |
| 公式数 | ≈905万 | ≈4074万（常数域宽 4.5 倍） |
| 基线 | 单码90% / 3杀全中72.9% | ≈94.6%（45对中当期同现2.43对） |
| 命中判定 | 杀码 ≠ 当期开奖位 | 预测对 ∉ 当期同现对集合 |
| 公式输出结构 | 3条独立公式(h/t/o) | 1条主推（v2：无备用、不撞期切换） |
| 硬约束 | 无 | 两数字不重复（mod45 查表天然满足） |
| 分桶 | 无需 | 按 v_next 分45桶取唯一主推 |

## 7. 已知限制与设计取舍

1. **命中率天花板**：两码不组随机基线 94.6% 已很高（45对只杀1对），穷举的 ~96% 是窗口拟合极值；样本外预期贴近基线。
2. **双窗口 300/500**：300 主窗口、500 副窗口作对比参考（网格扫描 500 期样本外极差最小=最稳）。公式随数据滚动会换（正常现象，非 bug）。
3. **（v2）不再跳过**：去掉撞上期约束后，每期必有预测；预测对偶与上期同现对相同，照常判定。
4. **无日期列**：CSV 只存期号与三码，跨年由期号序列逻辑处理（get_next_issue 按「>359 进位」；福彩3D 实际每年 351-352 期，2020 特殊 313 期，均远低于 359，故边界安全）。
5. **时区**：所有"北京时间"由 `timezone(timedelta(hours=8))` 显式构造，不依赖服务器时区。
6. **依赖锁版**：numpy 锁 `<3`，防版本升级改变 `%` 运算路径导致结果漂移。
7. **数据源易失效**：多源降级链 + 重试 + CSV 兜底保命（历史上已移除 3 个失效源）。
